## 9. 워크플로우 운영

### 9.1 세션 관리

- 작업당 1개 세션, 무관한 작업은 `/clear`로 분리
- 간단한 작업: `/effort low`, 복잡한 아키텍처: `/effort high`

### 9.2 자기 개선 루프

- 사용자로부터 수정을 받으면 즉시 `tasks/lessons.md`에 패턴 기록
- 새 세션 시작 시 `tasks/lessons.md` 검토

### 9.3 세션 간 연속성

- CLAUDE.md 하단 "Current Work" 섹션에 진행 중 작업을 기재
- 새 세션 시작 시 미완료 작업이 있으면 사용자에게 재개 여부 문의
- 작업 완료 시 "Current Work" 섹션에서 삭제

### 9.4 버그 수정

- 버그 리포트를 받으면 바로 수정한다. 로그, 에러, 실패 테스트를 확인하고 해결한다.

### 9.5 코드 리뷰

- 별도 지시가 없는 한 `/sc:analyze`로 수행한다.
